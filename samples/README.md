# Sample library: The Salt Road

`samples/the-salt-road` is a small, original library for the hackathon demo and for anyone who wants to
open a complete book without touching their own work.

- **Book:** *The Salt Road*, a lighthouse-keeper story written for this project.
- **Story Bible:** outline, three-act arc, Mara Venn, one memory.
- **Chapters:** two Markdown files with front matter.
- **Images:** a 1024×1024 chapter illustration and a 512×512 transparent character cutout, with
  `images.json` provenance.
- **No personal data:** no real library, account, key, email, path or author manuscript.

The text and the generated images are dedicated to the public domain under
[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). The application code remains Apache-2.0;
see [`LICENSE`](../LICENSE) and [`THIRD_PARTY_NOTICES.md`](../THIRD_PARTY_NOTICES.md).

## Open it

1. Open AI Book Studio.
2. Choose **Open library** and select `samples/the-salt-road`.
3. The app creates `.studio/` device identity and the derived catalog; those are not committed.
4. Never point the demo at a real author library.

The library is generated by `bun run film:fixture` and then committed without `.studio/` and
`library.json`. Regenerating it changes ids, timestamps and hashes; update the sample deliberately.
