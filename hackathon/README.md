## The short version

- Build on AI Book Studio, not a new app. It already has a local-first library, a writing agent,
  Story Bible, DOCX export and a tested desktop/web foundation.
- Add Meta's models where they change the product: Muse Spark and Muse Wonder for planning and prose,
  Muse Image for chapter illustrations and covers, SAM 3.1 for selecting and cutting out what the
  image contains, and Meta open weights through Baseten, Modal or Fireworks for cost and privacy.
- Apache-2.0 is already the project licence.

## Open decisions

1. **Track and team:** Indie developer if submitting solo; Startup only if the team and company are the
   submission. A team of up to four is allowed, and every contributor must be listed. The judging
   criteria differ.
2. **Repository shape:** three worktrees (recommended) or a new `meta-hackathon-2026` repository.
3. **Meta access:** Meta Model API directly, or Meta open weights through Baseten, Modal or Fireworks.
   This decides the provider adapter and the demo's cost profile.
4. **Demo story:** a public-domain text, or a short original sample written for the demo.
5. **Submission visibility:** public repository or private with judge access, as the official rules
   require.
